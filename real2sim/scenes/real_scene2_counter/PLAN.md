# real_scene2：茶水间吧台 建模说明

v1，依据两张手机照片：`reference/photo.jpg` 从右前方拍，`reference/photo2.jpg` 从左前方拍。两张照片联合拟合了相机位姿和尺寸，台面两端都能看到，所以台面长度已经有约束。尺度仍然只来自微波炉宽度的假设值，没有卷尺实测。场景变更时同步更新本文件。

## 文件

| 文件 | 作用 |
| --- | --- |
| `fit_photo.py` | 两张照片上手工标的角点和边线，联合反求两台相机的位姿、共享焦距和未测尺寸，写 `fit_photo.json` |
| `build_scene.py` | 读 `fit_photo.json`，生成 `usd/`（`background.usda`、`counter.usda`、`lights.usda`、`scene.usda`、贴图）和 RoboDojo Room 入口 `real_scene2.usd` |
| `check_scene.py` | 离线检查，写 `check_report.json` |
| `preview.py` | numpy 光栅化预览（`preview/`）。`compare_photo.jpg` 用两台拟合相机分别渲染，和对应照片并排；只核对几何和贴图，不代表 RTX 效果 |

运行（本机无 Isaac 也可）：

```bash
uv run --no-project --python 3.11 --with usd-core --with trimesh --with numpy --with shapely \
    --with opencv-python-headless --with scipy --with mapbox-earcut --with manifold3d \
    sh -c "python fit_photo.py && python build_scene.py && python check_scene.py && python preview.py"
```

## 坐标系

与 real_scene1 一致：Z 向上，米制；原点在台面中心正下方的地面；+X 沿台面，+Y 从机器人一侧指向墙。台面前沿 y = −D/2 = −0.28，墙面 y = +0.28。`fit_photo.py` 内部把墙放在 y = 0.30，`build_scene.py` 读入时平移。

## 尺寸与置信度（`fit_photo.json`）

拟合共用了约 60 个像素约束，大多数误差在 1–9 px，最大约 12 px。

| 项 | 取值 | 依据 | 置信度 |
| --- | --- | --- | --- |
| 台面长 | 2.43 m | 第二张照片能看到台面两端；只有第一张照片时拟合在 1.9–2.4 m 之间波动 | 中 |
| 台面高 | 0.833 m | 各种拟合设置下都在 0.829–0.835 | 中 |
| 台面进深 | 0.56 m | 拟合 | 中 |
| 台面前沿厚度 | 6.3 cm | 拟合；第二张照片的近端能清楚看到前沿立面 | 中 |
| 水槽 | 开口 0.50×0.35 m，中心 x = −0.22（偏左） | 两张照片的开口角点；圆角会带来约 1 cm 误差 | 中 |
| 水龙头 | x = −0.12，在水槽后沿、中线右侧约 10 cm | 两张照片的底座位置 | 中 |
| 两层架子 | 顶面高 1.50 / 1.79 m，进深 0.23 m；从左木柱伸到 x = 0.955，离右柱约 26 cm | 拟合 | 中 |
| 木柱前沿 | 左右两根都比台面前沿缩进约 2 cm | 两张照片里木柱的竖直边线 | 中 |
| 微波炉 | 0.485×0.31×0.29 m，左缘 x = 0.67，前沿 y = −0.10 | 宽和高是假设的尺度基准，进深和位置来自拟合 | 中 |
| 柜门 | 5 扇等宽，每扇约 0.49 m；无拉手，靠台面下的凹槽开门；最左一扇是投垃圾口 | 第二张照片的门缝反投影出的间距是 0.46–0.49 m | 中 |
| 海报 | 0.59×0.91 m，底边离地 1.86 m | 拟合；宽度和 A1 纸宽 0.594 m 一致 | 中 |
| 凹槽顶部（木吊顶） | 2.80 m | 第二张照片右上角的一个角点 | 低 |
| 插座 | 双联在 x = −0.30、z = 0.91；单个开关在 x = −0.96、z = 0.95 | 两张照片分别反投影，双联插座两次结果相差 2 cm | 中 |
| 右侧木柜墙和饮水机 | 两个凹槽在 x 2.97–3.40 和 3.45–3.85，z 0.78–1.36 | 第二张照片的像素反投影，看得很斜 | 低 |
| 左木柱宽度，以及背墙、侧墙 | 0.45 m；背墙在 y = −3.5 | 照片里看不到，纯假设 | 低 |

尺度只依赖“微波炉宽 0.485 m、高 0.29 m”这一个假设。海报宽度正好对上 A1 纸宽，台面高度也落在常见范围里，这两点说明尺度大致正确，但不能代替实测。

## 需要实测的尺寸（卷尺 10 分钟）

1. 台面长（左木柱到右木柱）、进深、离地高度、前沿厚度。
2. 微波炉的外形尺寸，它是目前唯一的尺度基准。
3. 水槽开口长宽、深度，到台面左端和前沿的距离；水龙头底座位置。
4. 两层架子的离地高度、进深、右端位置。

量到之后，整体比例不对就用 `build_scene.py --scale-correction` 缩放；单个尺寸不对，就在 `fit_photo.py` 里把对应先验的 sigma 调小，固定成实测值，重新拟合。

## 资产分层

- **`counter.usda` `/Counter`**：
  - 台面，带水槽开口和后挡水条；
  - 柜体，水槽上方挖空；
  - 5 扇无拉手柜门和台面下的凹槽，垃圾口门上有内嵌面板和标识贴花（从第二张照片裁出，用 alpha 镂空）；
  - 踢脚、水槽盆、沥水篮、水龙头、微波炉。

  碰撞体全部是静态盒体或凸包，purpose 为 guide。台面碰撞由水槽开口四周的 4 块盒体组成，开口不封闭；沥水篮占住水槽右半边。
- **`background.usda` `/Background`**：
  - 地面（水磨石）、大理石背板、木吊顶、左木柱；
  - 右侧木柜墙，带板缝、拉手槽和两格饮水机凹槽；
  - 左侧墙面和挂画、海报、插座；
  - 两层架子及架上物品（静态装饰，带简化碰撞）。
- **`lights.usda` `/Lights`**：3 块吊顶面光（RectLight，5000 K，强度 6000）和环境光 Dome（150）。**强度没有标定。** 第一版的 9000 / 4500 K 在 RTX 里过曝，大理石纹理看不出来，木纹偏橙。

贴图：
- **木纹**：从第一张照片截取，饱和度降低了 15%。
- **海报**：主体来自第二张照片，用拟合相机做透视校正；底部约五分之一换成第一张照片里更清晰的部分，并做了曝光匹配。
- **微波炉面板**：从第一张照片截取。
- **大理石和水磨石**：程序化生成的无缝贴图，颜色取自照片。

## 接入 RoboDojo

1. 把本目录整体拷到服务器 `Assets/Room/real_scene2/`。`layout_manager.select_room` 会加载目录下唯一的 `.usd`，也就是 `real_scene2.usd`。
2. 在评测布局里去掉 `Table`、`Ground`、`Background`，换成：

```json
"Room": {"default": "real_scene2", "default_pos": [-0.35, -0.32, 0.0], "default_ori": [1, 0, 0, 0],
         "scale": [1, 1, 1], "collision": false, "table_height": 0.833}
```

   - `default_pos` 的 y = −0.32 把台面前沿放到 RoboDojo 默认桌沿 y = −0.60。
   - x = −0.35 让水槽和微波炉之间约 0.64 m 宽的空台面正对机器人，水槽在左边，微波炉在右边。
   - `table_height` 让 `relative_plane: "Table"` 的物体落在台面上。
3. **机器人站位。** 吧台是落地柜，G1-D 底盘不能像在无腿桌下那样伸进去。
   - `check_scene.py` 按站立圆柱 r = 0.22 m 估算，机器人根节点要从 y = −0.73 移到 y ≤ −0.80。这一项检查会一直 FAIL，用来提醒这件事。
   - 台面比办公室桌面（0.68 m）高 0.15 m，用升降柱补：`LZ_mt_Joint` 和 `LZ_it_Joint` 各 0.075。
   - 物体要整体平移 (0, −0.07, +0.15)，这样和机器人的相对位置与办公室场景一样，倒水脚本不用改。
4. 灯光放在 Room 里，多环境并行时会每个环境各有一套，和 real_scene1 是同一个问题。

## 验证记录

- **2026-10-14，v0 场景（只依据第一张照片）**：服务器 `21196` 上用隔离目录跑了 `scripted_demo.py`，任务 `g1d_pour_water_into_cup`，seed 0。渲染正常，抓壶、举起、倾倒、回正都完成了；倒出约 7%，判据要求 ≥20%，和办公室场景一样失败。
- **v1 场景**：同一套流程，第三视角相机换成第一张照片的拟合位姿，可以和照片直接对比。

## 未覆盖（需要在 Isaac Sim 里验收）

- RTX 渲染效果：透明物体、金属水槽的反射、曝光；需要和真机头部相机画面对比后标定灯光强度。
- PhysX：物体在台面和水槽里静置是否稳定、机器人和柜体有无穿插、可达性。
- 摩擦系数是估计值。
